# Impact Cup 2026

Tournament-day GitHub Pages build.

## Public format
- Match 1 — Captain's Choice
- Match 2 — Best Ball / Four-Ball
- Match 3 — Singles
- Finale — details announced on the course

## Features
- Captain pairing selections
- Automatic handicap calculations
- Re-pairing tee-order optimizer
- Admin / Scoring mode
- Presentation Mode

## GitHub Pages
Publish from:
- Branch: `main`
- Folder: `/ (root)`

The finale details are intentionally omitted from the public-facing build.
